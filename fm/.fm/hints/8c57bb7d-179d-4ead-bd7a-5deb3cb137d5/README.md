# 최적화된 Irradiance 렌더링 식 $E(n)$

## 한 줄 답

법선 $n=(x,y,z)$에서의 Irradiance는 9개의 SH 계수 $L_{lm}$ ($l\le2$)와 5개의 상수 $c_1\ldots c_5$만으로 다음처럼 계산된다.

$$
\begin{aligned}
E(n)=\;& c_1L_{22}(x^2-y^2)+c_3L_{20}z^2+c_4L_{00}-c_5L_{20}\\
&+2c_1(L_{2-2}\,xy+L_{21}\,xz+L_{2-1}\,yz)\\
&+2c_2(L_{11}\,x+L_{1-1}\,y+L_{10}\,z)
\end{aligned}
$$

$$
c_1=0.429043,\quad c_2=0.511664,\quad c_3=0.743125,\quad c_4=0.886227,\quad c_5=0.247708
$$

Ramamoorthi & Hanrahan, *An Efficient Representation for Irradiance Environment Maps* (SIGGRAPH 2001, 원문 글의 레퍼런스 3번) 3.2절의 식이다.

## 어디서 나온 식인가

원문 글은 Irradiance Map(Diffuse IBL용 큐브맵)을 구면 조화 함수(SH)로 대체하는 과정을 다룬다. 흐름을 정리하면:

1. **Irradiance 정의**: 법선 $n$ 주위 반구에서 들어오는 Radiance $L$을 $\cos\theta$ 가중으로 적분한 것.
   $$E(n)=\int_{\Omega(n)} L(\omega)\,(n\cdot\omega)\,d\omega$$
2. **두 함수를 SH로 투영**: 환경광 $L(\omega)$의 계수 $L_{lm}$, 그리고 클램프된 코사인 $\max(\cos\theta,0)$의 계수 $A_l$ (천정각에만 의존하므로 $m=0$).
3. **Irradiance의 SH 계수는 곱으로 나온다** (컨볼루션 정리의 구면 버전):
   $$E_{lm}=\hat A_l L_{lm},\qquad \hat A_l=\sqrt{\tfrac{4\pi}{2l+1}}A_l$$
   $$\hat A_0=\pi\approx3.1416,\quad \hat A_1=\tfrac{2\pi}{3}\approx2.0944,\quad \hat A_2=\tfrac{\pi}{4}\approx0.7854,\quad \hat A_3=0,\quad \hat A_4\approx-0.1309,\ldots$$
4. **$l\le2$까지만 남긴다**. $\hat A_l$이 급격히 줄기 때문에 9개 계수(RGB면 27개)만으로 Irradiance를 1% 안팎 오차로 근사할 수 있다.

![클램프 코사인의 SH 계수 Â_l — l=0,1,2 이후 거의 0](fig-1.png)

위 그래프(레퍼런스 4번 논문)에서 $l=0,1,2$에서 값이 크고, $l=3$에서 정확히 0, $l\ge4$부터는 진폭 0.1 이하로 진동하며 사라진다. 이것이 "$l\le2$로 충분하다"는 근거이고, $E(n)$ 식이 2차 다항식으로 끝나는 이유다.

## 식이 어떻게 이 모양으로 정리되는가

복원식 $E(n)=\sum_{l\le2,m}\hat A_l L_{lm}\,Y_l^m(n)$에 실수 SH 기저(직교좌표 표현)를 대입한다.

| $Y_l^m(n)$ | 식 | 상수 |
|---|---|---|
| $Y_{00}$ | $0.282095$ | $\tfrac{1}{2}\sqrt{1/\pi}$ |
| $Y_{1-1},Y_{10},Y_{11}$ | $0.488603\,(y,\ z,\ x)$ | $\tfrac{1}{2}\sqrt{3/\pi}$ |
| $Y_{2-2},Y_{2-1},Y_{21}$ | $1.092548\,(xy,\ yz,\ xz)$ | $\tfrac{1}{2}\sqrt{15/\pi}$ |
| $Y_{20}$ | $0.315392\,(3z^2-1)$ | $\tfrac{1}{4}\sqrt{5/\pi}$ |
| $Y_{22}$ | $0.546274\,(x^2-y^2)$ | $\tfrac{1}{4}\sqrt{15/\pi}$ |

$\hat A_l$과 기저 상수를 곱해 미리 접어 넣은 것이 $c_1\ldots c_5$다. 직접 확인해 보면 정확히 맞는다.

| 상수 | 유도 | 값 |
|---|---|---|
| $c_4$ | $\hat A_0\cdot0.282095=\pi\cdot0.282095$ | $0.886227$ |
| $c_2$ | $\hat A_1\cdot0.488603/2=\tfrac{2\pi}{3}\cdot0.488603/2$ | $0.511664$ |
| $c_1$ | $\hat A_2\cdot0.546274=\tfrac{\pi}{4}\cdot0.546274$ | $0.429043$ |
| $2c_1$ | $\hat A_2\cdot1.092548$ | $0.858086$ (= $2\times0.429043$, 그래서 같은 $c_1$을 재사용) |
| $c_3$ | $\hat A_2\cdot0.315392\cdot3$ ($Y_{20}$의 $3z^2$ 항) | $0.743125$ |
| $c_5$ | $\hat A_2\cdot0.315392$ ($Y_{20}$의 $-1$ 항) | $0.247708$ |

즉:
- $c_4L_{00}$ : $l=0$ 항 (평균 밝기)
- $2c_2(L_{11}x+L_{1-1}y+L_{10}z)$ : $l=1$ 항 (빛의 대략적인 방향)
- $c_1L_{22}(x^2-y^2)+2c_1(\cdots)$ : $l=2$의 $m\ne0$ 항
- $c_3L_{20}z^2-c_5L_{20}$ : $Y_{20}=0.315392(3z^2-1)$을 $z^2$ 항과 상수항으로 분리한 것. 상수 $-c_5L_{20}$은 $L_{00}$ 항과 함께 "$n$에 무관한 바탕값"을 이룬다.

$Y_{22}$의 계수 $0.546274$가 $Y_{2-2},Y_{21},Y_{2-1}$의 $1.092548$의 정확히 절반이므로, 하나의 $c_1$로 다섯 항을 모두 표현할 수 있다. 이것이 "최적화"의 핵심: 곱셈·덧셈 십수 회, 텍스처 조회 없음.

논문에서는 같은 식을 $4\times4$ 대칭 행렬 $M$으로 묶어 $E(n)=n^TMn$ ($n=(x,y,z,1)$) 꼴로도 제시한다. 위 식은 그 행렬을 전개한 것과 같다.

## 셰이더 코드와의 대응

원문 글의 `ImageBasedLight(normal)`은 이 식을 그대로 옮긴 것이다. 계수 $L_{lm}$은 RGB 각각 따로 저장되므로 `float3` 9개, 상수 `c1~c5`는 `static const float`, 리턴문 한 줄이 $E(n)$ 전체다.

```
return c1 * l22 * (n.x*n.x - n.y*n.y) + c3 * l20 * n.z*n.z + c4 * l00 - c5 * l20
     + 2*c1 * (l2_2 * n.x*n.y + l21 * n.x*n.z + l2_1 * n.y*n.z)
     + 2*c2 * (l11 * n.x + l1_1 * n.y + l10 * n.z);
```

주의: 원문에서 SH 계수 $L_{lm}$을 구할 때 $L(\theta,\phi)Y_l^m\sin\theta\,d\theta d\phi$ 적분을 큐브맵 샘플링으로 계산하고, 결과에 컨볼루션 가중치 $\hat A_l$은 넣지 **않는다**. $\hat A_l$이 이미 $c_1\ldots c_5$에 포함되어 있기 때문이다. 이 식을 쓸 때는 반드시 "Radiance의 SH 계수"를 넣어야 하며, "Irradiance의 SH 계수 $E_{lm}$"을 넣으면 $\hat A_l$이 두 번 곱해진다.

## 기억용 요약

- **무엇**: 법선 $n$에 대한 Diffuse Irradiance를 2차 다항식으로 계산하는 식.
- **입력**: 환경광의 SH 계수 9개 $L_{00},L_{1-1},L_{10},L_{11},L_{2-2},L_{2-1},L_{20},L_{21},L_{22}$ (RGB별).
- **상수**: $c_1..c_5$ = 클램프 코사인 계수 $\hat A_l$ × SH 기저 정규화 상수를 미리 곱한 것.
- **구조**: $l=0$ 상수항 + $l=1$ 1차항($2c_2$) + $l=2$ 2차항($c_1$, $c_3$, $c_5$).
- **출처**: Ramamoorthi & Hanrahan 2001, 3.2절.
