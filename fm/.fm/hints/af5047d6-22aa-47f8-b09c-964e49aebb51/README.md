# 기저 함수(Basis Function)란 무엇인가?

## 한 줄 정의

**기저 함수**는 "미리 정해 둔 간단한 함수들의 모음"으로, 이들을 **선형 조합**(계수를 곱해서 더하기)하면 복잡한 원래 함수를 근사(또는 정확히 표현)할 수 있는 함수다.

$$
f(x) \approx c_1 b_1(x) + c_2 b_2(x) + c_3 b_3(x) + \cdots = \sum_i c_i\, b_i(x)
$$

- $b_i(x)$ : 기저 함수 (미리 정해진 "재료" 함수)
- $c_i$ : 계수 (각 재료를 얼마나 섞을지 나타내는 숫자)
- $f(x)$ : 표현하려는 원래 함수

핵심은 **함수 $f$ 전체를 저장하는 대신, 숫자 몇 개($c_1, c_2, \dots$)만 저장하면 된다**는 점이다. 기저 함수 $b_i$는 양쪽(저장하는 쪽·복원하는 쪽)이 이미 알고 있으므로 계수만 주고받으면 함수를 재구성할 수 있다.

## 벡터와의 비유

3차원 공간의 임의 벡터는 $\vec v = v_x \hat x + v_y \hat y + v_z \hat z$처럼 세 기저 벡터 $\hat x, \hat y, \hat z$의 선형 조합으로 쓸 수 있고, 벡터 자체 대신 좌표 $(v_x, v_y, v_z)$만 기록해도 충분하다. 기저 함수는 이 아이디어를 "함수"에 그대로 옮긴 것이다.

| 벡터 세계 | 함수 세계 |
|---|---|
| 기저 벡터 $\hat x, \hat y, \hat z$ | 기저 함수 $b_1(x), b_2(x), \dots$ |
| 좌표(성분) $v_x, v_y, v_z$ | 계수 $c_1, c_2, \dots$ |
| 내적 $\vec v \cdot \hat x = v_x$ | 적분 $\int f(x) b_i(x)\,dx = c_i$ |
| $\vec v = \sum v_i \hat e_i$ | $f(x) = \sum c_i b_i(x)$ |

## 계수는 어떻게 구하나 — 투영(Projection)

기저 함수들이 **정규 직교**(서로 다른 기저끼리의 곱을 적분하면 0, 자기 자신과의 곱을 적분하면 1)라면, 계수는 원 함수와 기저 함수의 곱을 전 구간에서 적분해서 얻는다. 이 과정을 **투영**이라 한다.

$$
c_i = \int f(x)\, b_i(x)\, dx
$$

원문 글(Green, *Spherical Harmonic Lighting: The Gritty Details*)의 그림이 이 과정을 잘 보여 준다.

![투영: 원 함수 × 기저 함수를 적분하면 계수](fig-1.png)

그림의 각 행을 보면 왼쪽에 **동일한 원 함수**(구불구불한 곡선)가 있고, 가운데에 서로 다른 위치에 놓인 **삼각형 모양의 기저 함수** $b_1, b_2, b_3$가 있다. 두 함수를 곱해 적분($\int$)하면 오른쪽의 계수 $c_1, c_2, c_3$가 하나씩 나온다. 삼각형 기저는 특정 구간에서만 0이 아니므로, 각 계수는 "그 구간 근처에서 원 함수의 값이 얼마나 큰가"를 요약한 숫자가 된다.

## 원 함수 복원 — 계수 × 기저 함수를 더하기

![복원: 계수 × 기저 함수](fig-2.png)

이번에는 반대 방향이다. 각 기저 함수 $b_i$에 방금 구한 계수 $c_i$를 곱한다. 오른쪽을 보면 삼각형의 **위치는 그대로**이고 **높이만 $c_i$에 비례해서** 바뀐 것이 보인다(첫 행은 낮아지고, 둘째·셋째 행은 높아짐).

![합산: 근사 결과와 원 함수 비교](fig-3.png)

이렇게 스케일된 조각들을 모두 더하면($\sum c_i B_i$) 오른쪽의 꺾은선 그래프가 나온다. 점선이 원래 함수, 굵은 실선이 근사 결과다. 기저 함수가 삼각형이므로 결과는 꺾은선(선형 보간) 형태가 되고, 원 함수의 큰 흐름은 잘 따라가지만 세부(부드러운 굴곡)는 다소 뭉개진다. **기저 함수를 더 많이(더 촘촘하게) 쓰면 근사가 더 정확해지고, 적게 쓰면 저장 비용은 줄지만 오차가 커진다** — 이것이 기저 함수 표현의 기본 트레이드오프다.

## 기저 함수의 대표적인 예

| 기저 | 형태 | 쓰이는 곳 |
|---|---|---|
| 다항식 $1, x, x^2, \dots$ | 테일러 급수 | 국소 근사 |
| 삼각 함수 $\sin nx, \cos nx$ | 푸리에 급수 | 신호 처리, 음향 |
| 삼각형(hat) 함수 | 선형 보간 | 유한 요소법, 위 그림 |
| **구면 조화 함수** $Y_l^m(\theta,\phi)$ | 구면 위의 푸리에 급수 | 조명(Irradiance Map), 3D Gaussian Splatting의 뷰 의존 색상 |

## 이 글(구면 조화 함수)에서 기저 함수가 왜 중요한가

원문은 Irradiance Map(구면 위 모든 방향에서 들어오는 빛의 세기)을 텍스처로 저장하지 않고 **구면 조화 함수를 기저로 삼아 계수 몇 개로 압축**하려는 맥락에서 기저 함수를 소개한다.

- 기저 함수 $b_i$ ↔ 구면 조화 함수 $y_l^m(\vec n)$ (예: $y_0^0 = 0.282095$, $y_1^0 = 0.488603\,z$, ...)
- 변수 $x$ ↔ 구면 위의 방향 $\vec n = (x, y, z)$
- 적분 $\int f b_i\,dx$ ↔ 구면 전체에 대한 적분 $\int_{S^2} L(\vec n)\, y_l^m(\vec n)\, d\omega$
- $l = 2$까지 쓰면 기저가 9개이므로, 채널당 **계수 9개**만으로 확산광(diffuse) 조명을 충분히 근사할 수 있다.

nerfstudio의 splatfacto(3DGS)에서도 각 가우시안의 색상을 `sh_degree`까지의 구면 조화 계수로 저장하는데, 이것 역시 "보는 방향에 따라 달라지는 색상 함수"를 기저 함수 계수로 압축한 것이다.

## 요약

- 기저 함수 = 선형 조합으로 다른 함수를 근사할 수 있는 "재료 함수" 집합.
- 표현: $f(x) = \sum_i c_i b_i(x)$.
- 계수 구하기(투영): $c_i = \int f(x) b_i(x)\,dx$ (정규 직교 기저일 때).
- 복원: 계수 × 기저를 모두 더한다. 기저 개수가 많을수록 정확, 적을수록 압축.
- 구면 조화 함수는 구면 위 함수(조명, 뷰 의존 색상)를 위한 대표적 기저 함수다.
