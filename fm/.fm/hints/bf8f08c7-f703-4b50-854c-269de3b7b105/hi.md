# 버금 르장드르 다항식 재귀의 "시작점" — $P_m^m$

## 1. 먼저 큰 그림: 왜 재귀가 필요한가

버금 르장드르 다항식 $P_l^m(x)$는 두 개의 정수 첨자를 가진 함수입니다. $x$는 $-1 \le x \le 1$ 범위의 실수(구면 조화 함수에서는 $x=\cos\theta$)이고, $l = 0, 1, 2, \dots$, $m = 0, 1, \dots, l$ 입니다. 첨자를 표처럼 늘어놓으면 삼각형 모양이 됩니다.

$$
\begin{array}{cccc}
P_0^0 \\
P_1^0 & P_1^1 \\
P_2^0 & P_2^1 & P_2^2 \\
P_3^0 & P_3^1 & P_3^2 & P_3^3
\end{array}
$$

각 칸에 대해 공식을 따로 외우는 대신, 고교에서 배운 **수열의 점화식**처럼 "앞의 항으로 다음 항을 만드는 규칙"을 씁니다. 원문은 세 가지 규칙을 소개합니다.

1. $P_m^m = (-1)^m (2m-1)!!\,(1-x^2)^{m/2}$  ← **시작점**
2. $P_{m+1}^m = x(2m+1)P_m^m$
3. $(l-m)P_l^m = x(2l-1)P_{l-1}^m - (l+m-1)P_{l-2}^m$

## 2. 점화식에는 반드시 "초항"이 필요하다

등차수열 $a_{n+1} = a_n + d$를 아무리 알아도 $a_1$을 모르면 값을 하나도 구할 수 없습니다. 위 규칙 2, 3도 마찬가지입니다.

- 규칙 2는 $P_m^m$을 알아야 $P_{m+1}^m$을 구합니다.
- 규칙 3은 $P_{l-1}^m$, $P_{l-2}^m$ 두 개를 알아야 $P_l^m$을 구합니다.

즉 둘 다 **이전 결과에 의존**합니다. 반면 규칙 1은 우변에 다른 $P$가 전혀 없고, $m$과 $x$만 넣으면 곧바로 값이 나옵니다. 그래서 "이전 결과와 연관 관계가 없어 재귀의 시작점으로 적합하다"고 말하는 것입니다. 삼각형 표로 보면 규칙 1은 **대각선(빗변) 위의 칸** $P_0^0, P_1^1, P_2^2, \dots$를 직접 채우고, 규칙 2가 그 바로 아래 칸을, 규칙 3이 같은 열을 따라 아래로 내려가며 나머지를 채웁니다.

## 3. 식 속 기호 하나씩 뜯어보기

$$P_m^m = (-1)^m \,(2m-1)!!\,(1-x^2)^{m/2}$$

### $(-1)^m$
$m$이 짝수면 $+1$, 홀수면 $-1$. 부호를 번갈아 바꾸는 관례(Condon–Shortley 위상)입니다. 부호 규약이니 의미를 깊이 따질 필요 없이 "홀수 $m$이면 마이너스"로 기억하면 됩니다.

### $(2m-1)!!$ — 이중 계승(double factorial)
고교의 계승 $n! = n(n-1)(n-2)\cdots 1$은 1씩 줄이며 곱합니다. 이중 계승 $n!!$은 **2씩 줄이며** 곱합니다.

$$
n!! =
\begin{cases}
n\cdot(n-2)\cdots 5\cdot 3\cdot 1 & (n\text{ 홀수}) \\
n\cdot(n-2)\cdots 6\cdot 4\cdot 2 & (n\text{ 짝수})
\end{cases}
$$

$2m-1$은 항상 홀수이므로 홀수만 곱한 값입니다.

| $m$ | $2m-1$ | $(2m-1)!!$ |
|---|---|---|
| 0 | $-1$ | $1$ (약속: $(-1)!! = 1$) |
| 1 | 1 | $1$ |
| 2 | 3 | $3\cdot1 = 3$ |
| 3 | 5 | $5\cdot3\cdot1 = 15$ |
| 4 | 7 | $7\cdot5\cdot3\cdot1 = 105$ |

### $(1-x^2)^{m/2}$
$(1-x^2)^{m/2} = \left(\sqrt{1-x^2}\right)^m$ 입니다. $x = \cos\theta$를 대입하면 $\sqrt{1-\cos^2\theta} = \sin\theta$ ($0 \le \theta \le \pi$)이므로 사실상 $\sin^m\theta$입니다. $|x| \le 1$이어야 근호 안이 음수가 되지 않는다는 점도 여기서 나옵니다.

## 4. 직접 계산해 보기

- $m=0$: $P_0^0 = (+1)\cdot 1 \cdot (1-x^2)^0 = 1$. 원문이 "$P_0^0(x) = 1$을 초기 상태로 놓는다"고 한 것과 일치합니다.
- $m=1$: $P_1^1 = (-1)\cdot 1\cdot\sqrt{1-x^2} = -\sqrt{1-x^2}$
- $m=2$: $P_2^2 = (+1)\cdot 3\cdot(1-x^2) = 3(1-x^2)$
- $m=3$: $P_3^3 = (-1)\cdot 15\cdot(1-x^2)^{3/2} = -15(1-x^2)^{3/2}$

이제 예컨대 $P_2^1$이 필요하면 $P_1^1 = -\sqrt{1-x^2}$에서 출발해 규칙 2를 쓰면 $P_2^1 = x\cdot 3 \cdot P_1^1 = -3x\sqrt{1-x^2}$가 됩니다.

## 5. 코드에서는 어떻게 보이나

원문 코드의 앞부분이 바로 규칙 1입니다.

```
double pmm = 1.0;                       // m = 0 이면 P_0^0 = 1
double somx2 = sqrt((1-x)*(1+x));       // sqrt(1 - x^2)
double fact = 1.0;
for (i = 1; i <= m; i++) {
    pmm *= (-fact) * somx2;             // (-1) × 홀수 × sqrt(1-x^2) 를 m번 곱함
    fact += 2.0;                        // 1, 3, 5, ... 홀수를 차례로
}
```

반복문이 $m$번 돌면서 $(-1)$을 $m$번(→ $(-1)^m$), 홀수 $1,3,5,\dots,2m-1$을 차례로(→ $(2m-1)!!$), $\sqrt{1-x^2}$를 $m$번(→ $(1-x^2)^{m/2}$) 곱하니 식과 정확히 같습니다. 그리고 이 `pmm`을 씨앗으로 규칙 2, 3이 이어집니다.

## 6. 한 줄 요약

세 재귀식 중 $P_m^m = (-1)^m(2m-1)!!(1-x^2)^{m/2}$만 다른 $P$ 값 없이 닫힌 형태로 바로 계산되므로, 수열의 초항처럼 재귀의 **시작점** 역할을 한다.
