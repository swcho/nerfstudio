# 버금 르장드르 다항식의 표기와 입력/출력 범위

## 핵심 요약

| 항목 | 내용 |
|---|---|
| 기호 | 전통적으로 $P$ |
| 인자 | 두 개 — $l$ (band index), $m$ (order) |
| 표기 | $P_l^m(x)$ |
| 입력 $x$ | $-1 \le x \le 1$ |
| 출력 | **실수** (real) |

## 왜 $x$가 -1 ~ 1인가

구면 조화 함수에서 $P_l^m$은 항상 $P_l^m(\cos\theta)$ 형태로 호출됩니다. 극각 $\theta$가 $0 \sim \pi$이므로 $\cos\theta$는 정확히 $-1 \sim 1$ 범위를 훑습니다. 즉 입력 범위 $[-1, 1]$은 "단위구 위의 한 점의 z좌표"에 해당하며, 다항식 안의 $(1-x^2)^{m/2} = \sin^m\theta$ 항도 이 범위에서만 실수로 정의됩니다.

## 왜 출력이 실수인가 — 일반 르장드르와의 혼동 주의

원문의 경고:

> 💡 복소수를 반환하는 일반 르장드르 다항식과 혼동하지 않도록 주의해야 합니다.

- Wikipedia 등에서 보는 "일반적인" 구면 조화 함수 $Y_l^m(\theta,\phi) = A\,P_l^m(\cos\theta)\,e^{im\phi}$는 $e^{im\phi}$ 때문에 복소수를 반환합니다.
- 그래픽스/Splatfacto에서 쓰는 **실수 구면 조화 함수** $y_l^m$은 $\cos(m\varphi)$, $\sin(-m\varphi)$로 분리해 실수만 다루며, 그 안에서 $P_l^m$은 실수를 반환하는 순수 실함수입니다.

## 인자 $l$, $m$의 범위 (표기와 함께 기억)

- $l$: **Band Index**, 0부터 시작하는 음이 아닌 정수 → 다항식을 대역(band)으로 나눔
- $m$: $0 \le m \le l$ 인 정수 (버금 르장드르에서는 음수 없음)

$$P_0^0 \\ P_1^0\; P_1^1 \\ P_2^0\; P_2^1\; P_2^2$$

주의: 구면 조화 함수 $y_l^m$에서는 $m$이 $-l \sim l$로 확장되지만, 음수 $m$일 때 내부적으로는 $P_l^{-m}$ 대신 $P_l^{|m|}$을 호출합니다. 즉 $P$ 자체는 여전히 $0 \le m \le l$만 받습니다.

## 값을 실제로 구하는 방법 (3가지 재귀식)

1. 시작점 (이전 결과 불필요): $P_m^m = (-1)^m (2m-1)!! \,(1-x^2)^{m/2}$
2. $P_{m+1}^m = x(2m+1) P_m^m$
3. $(l-m)P_l^m = x(2l-1)P_{l-1}^m - (l+m-1)P_{l-2}^m$

$P_0^0(x) = 1$을 초기 상태로 삼아 위 세 식만으로 모든 $P_l^m(x)$를 계산할 수 있습니다. 원문의 `double P(int l, int m, double x)` 함수 시그니처가 그대로 **"$P$, 인자 $l$·$m$, 실수 입력 $x$, 실수 반환"**이라는 이 카드의 답을 코드로 보여줍니다.

## 간단한 확인 예

- $P_0^0(x) = 1$
- $P_1^0(x) = x$
- $P_1^1(x) = -\sqrt{1-x^2}$ ($x=0$이면 $-1$, $x=\pm1$이면 $0$)
- $P_2^0(x) = \tfrac{1}{2}(3x^2-1)$

모두 $x \in [-1,1]$에서 실수값을 내며, 이 값들에 정규화 계수 $K_l^m$과 $\cos/\sin(m\varphi)$를 곱하면 실수 구면 조화 함수가 됩니다.
