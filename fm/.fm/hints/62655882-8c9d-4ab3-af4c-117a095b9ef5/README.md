# $\hat{A_l}$ 분포의 특징과 결론 — 왜 $l \le 2$ 면 충분한가

## 한 줄 요약

$\hat{A_l}$ 은 $l$ 이 커질수록 **매우 빠르게 0 으로 감소**한다. 따라서 $l \le 2$ 의 낮은 주파수 구면 조화 함수(SH 계수 9개, RGB 포함 27개)만으로도 Irradiance Map 을 충분히 근사할 수 있다.

## $\hat{A_l}$ 이 무엇인가

Irradiance 는 반구에 대해 Radiance 에 $\cos\theta$ 를 곱해 적분한 값이다. 이를 두 부분으로 나눠 각각 구면 조화 함수로 투영한다.

- $L_{lm}$ : 환경맵(Radiance)의 SH 계수 — 조명이 바뀌면 달라지는 값
- $A_l$ : 클램프된 코사인 $\max(\cos\theta, 0)$ 의 SH 계수 — 천정각에만 의존하므로 $m = 0$, **조명과 무관한 상수**

Irradiance 의 SH 계수는 두 계수의 곱으로 얻어진다.

$$E_{lm} = \sqrt{\tfrac{4\pi}{2l+1}}\,A_l\,L_{lm} = \hat{A_l}\,L_{lm}$$

여기서 $\sqrt{4\pi/(2l+1)}$ 은 로컬 좌표에서 구한 $\cos\theta$ 계수를 월드 좌표로 회전시키기 위한 가중치이고, 이를 $A_l$ 과 묶어 미리 계산한 상수가 $\hat{A_l}$ 이다.

## 관찰되는 특징: 급격한 감소

원문에 정리된 값은 다음과 같다.

| $l$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $\hat{A_l}$ | 3.1415 | 2.0943 | 0.7853 | 0 | −0.1309 | 0 | 0.0490 |

세 가지가 눈에 띈다.

1. **$l = 0,1,2$ 에 에너지가 집중** — $\pi$, $2\pi/3$, $\pi/4$ 로 세 항이 지배적이다.
2. **홀수 $l \ge 3$ 은 정확히 0** — 클램프된 코사인 $\max(\cos\theta,0)$ 의 대칭성 때문에 $l = 3, 5, 7, \dots$ 항은 사라진다.
3. **짝수 $l \ge 4$ 는 부호가 번갈아가며 크기가 급감** — $\hat{A_4} \approx -0.13$, $\hat{A_6} \approx 0.05$ 로 $\hat{A_0}$ 의 4%, 1.5% 수준이다. 점근적으로 $A_l \sim l^{-2}$ 로 줄어든다.

![Lambertian BRDF(클램프 코사인) SH 계수 A_l 의 그래프](fig-1.png)

위 그림은 Ramamoorthi & Hanrahan 의 논문에서 가져온 것으로, 가로축이 차수 $l$, 세로축이 $A_l$ 이다(정규화 가중치 $\sqrt{4\pi/(2l+1)}$ 을 곱하기 전의 값이라 세로축 수치는 $\hat{A_l}$ 과 다르다. 예: $A_0 \approx 0.886$, $\times\sqrt{4\pi} \approx 3.14 = \hat{A_0}$). 그래프에서 실제로 확인되는 것은

- $l = 0$ 에서 약 0.89, $l = 1$ 에서 최댓값 약 1.02, $l = 2$ 에서 약 0.5 — 처음 세 점만 크게 솟아 있다.
- $l = 3$ 에서 정확히 0 선(점선)에 닿고, $l = 4$ 에서 약 −0.11 로 살짝 음수, $l = 6$ 에서 약 0.05.
- $l \ge 7$ 부터는 0 선에 거의 붙어 있어 점들이 구분되지 않는다.

즉 **클램프 코사인은 본질적으로 저주파 함수**이다. Irradiance 는 Radiance 에 이 저주파 필터를 곱하는 것(주파수 영역에서는 $E_{lm} = \hat{A_l} L_{lm}$)이므로, 환경맵 $L_{lm}$ 이 아무리 고주파 성분을 많이 가져도 $l \ge 3$ 항은 $\hat{A_l}$ 에 의해 거의 소멸한다.

## 얻는 결론

- $l \le 2$ 까지만 취해도 전체 에너지의 99% 이상이 보존된다(Ramamoorthi & Hanrahan 은 평균 오차 1% 미만, 최대 오차 약 3% 로 보고).
- 따라서 Irradiance Map 은 **$l = 0,1,2$ 의 SH 계수 9개 × RGB 3채널 = 27개 부동소수(108 Byte)** 로 표현할 수 있다. 32×32 큐브맵(약 24 KB)과 비교해 200배 이상 작다.
- 셰이더에서는 $\hat{A_l}$ 을 정규화 상수와 합쳐 미리 계산한 $c_1 \dots c_5$ (0.429043, 0.511664, 0.743125, 0.886227, 0.247708) 를 사용해 법선 $\vec n$ 의 2차 다항식으로 Irradiance 를 즉시 복원한다.

두 렌더링은 육안으로 구분이 어렵다. 이것이 "$\hat{A_l}$ 이 빠르게 감소하므로 $l \le 2$ 로 충분하다"는 결론의 실증이다.
